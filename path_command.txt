Commands to Run Everything
You need THREE terminals open:
Terminal 1 — MySQL (must be running):
bash
sudo systemctl start mysql
Terminal 2 — Backend (Laravel API):
bash
cd ~/Order-Management-System/server
php artisan serve --host=0.0.0.0 --port=8000
Terminal 3 — Frontend (React):
bash
cd ~/Order-Management-System/client
npm start
Then open browser:
Frontend: http://localhost:3000
API test: http://localhost:8000/api/products
What We Fixed
Table
#	Problem	Fix
1	Missing PHP/Composer/MySQL	Installed PHP 8.3, Composer, MySQL server on Ubuntu
2	Wrong DB credentials in .env	Database was laravel, username laravel_user, password Laravel@12345 — not the order_management we first created
3	Empty API response []	Products existed but the ProductController::index() does an INNER JOIN with thumbnails table. Products had no thumbnails, so join returned nothing.
4	No thumbnails in DB	Inserted 5 thumbnail records via Tinker so the product grid would render
5	No images in DB	Inserted 5 image records via Tinker so the product detail page wouldn't crash with Cannot read properties of undefined (reading 'image')
6	Frontend showed 0 products	products-actions.js had a dead debug line: axios.get('http://localhost:8000/src/client.php') which threw a 500 error and killed the Redux dispatch. Deleted that line.
7	CORS config	Added SANCTUM_STATEFUL_DOMAINS, SESSION_DOMAIN, and FRONTEND_URL to .env so React could talk to Laravel

Quick Health Check Commands
Before any demo call, run these to confirm everything is alive:
bash
# 1. Is MySQL running?
sudo systemctl status mysql | grep Active

# 2. Is backend responding?
curl -s http://127.0.0.1:8000/api/products | head -c 100

# 3. Is frontend building?
curl -s -o /dev/null -w "%{http_code}" http://localhost:3000
If all three return good output, you're live.
